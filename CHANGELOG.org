#+TITLE: Changelog
#+OPTIONS: toc:nil ^:{}

All notable changes to slothbar are recorded here. Slothbar is pre-1.0, so
internal and configuration APIs may still change between releases.

* 0.31.0 - 2026-11-10

This section covers the work since commit
=5b1b7f5c45e5e468754c6e676e97223529cd4575= (2026-09-13).

** Added

*** Display backends and multi-bar support
- Add a Wayland backend using elwl and =wlr-layer-shell=, alongside the
  existing xcb/X11 backend.
- Add automatic backend selection: use Wayland when a compositor socket and
  elwl are available, otherwise use xcb. Either backend can be selected
  explicitly with =slothbar-backend=.
- Add =slothbar-bars= for multiple bars. Each bar can select:
  - its own output by name
  - one bar per connected output with =:output :each=
  - multiple bars on the same output by using multiple =:each= entries
- Add live output hotplug handling on Wayland and RandR-aware output changes
  on X11
- Add stable bar identity through =:id=, with in-place runtime
  reconfiguration and reconciliation
- Add per-bar geometry, font sizes, theme colors, visibility, and damage
  state
- Make elwl optional at package load time so X11-only builds and installs do
  not require it. Requesting the Wayland backend without elwl now reports a
  clear =user-error=.

*** Input and interaction
- Add pointer button and motion routing to the bar under the pointer on both
  backends.
- Add hover notifications and workspace-extent hover highlighting.
- Add click dispatch to modules, including workspace activation on
  ext-workspace, EWMH, and EXWM.
- Add =^B=/=^b= bright styling and =^M<x>= / =^M;= extent markers for
  clickable or hoverable regions.

*** Modules
- Add the focus module, showing the focused window title and application id.
- Add the sysinfo module with a field registry, data providers, formatting
  plans, and support for CPU, memory, disk, network, load, uptime, processes,
  thermal, power, battery, and general system information.
- Add ext-workspace-v1 support to the workspaces module, including
  output/group-aware workspace lists.
- Make the XEmbed tray a global singleton across bars.
- Add per-module backend support checks so modules are skipped on backends
  that cannot provide their facilities.
- Add module init/refresh/update failure containment. A failing module is
  logged and warned about, disabled, and no longer prevents the remaining
  modules or bars from starting.

*** Rendering and fonts
- Add backend-neutral text draw operations between fontsloth layouts and the
  X/Wayland renderers.
- Add damage-tracked, partial repainting for both backends.
- Add a frame-reuse path and skip clean bars to reduce Wayland redraw CPU and
  allocation pressure.
- Add =slothbar-font-px-scale=, live =slothbar-font-candidates= refresh, and
  per-bar font pixel sizes.
- Add vertical line-box centering and corrected Wayland glyph placement.
- Add the =slothbar-format-compile= token/plan compiler with padding,
  truncation, precision, and per-token decimal support.
- Add neutral 16-bit RGBA colors, with XRender conversion isolated in the X
  renderer.
- Add font cache reuse through preferred nerd-bundle fonts and a cold-cache
  benchmark task.

** Changed

- Split the display backend interface into shared backend state and per-bar
  surfaces, with the X and Wayland implementations kept behind backend
  methods.
- Make theme changes, font-size changes, and font-candidate changes refresh
  every affected bar.
- Make workspace lists group/ output aware instead of sharing one global
  workspace view.
- Share focus backend subscriptions and the sysinfo provider across module
  instances, avoiding duplicate hooks and polling.
- Replace the old X-specific color pipeline with the neutral color model.
- Update the usage documentation, README, and DESIGN for multi-bar,
  multi-output, and HiDPI behavior.

** Fixed

- Fix the X initial-paint issue by forcing a bar redraw on Expose.
- Fix Wayland HiDPI buffer sequencing by presenting scale, buffer, damage,
  and commit atomically through =elwl-surface-present=.
- Fix Wayland output scale changes fanning out to every bar on the output.
- Fix runtime bar geometry: width, height, offsets, and modules are now
  reflected in live bars and their backend surfaces.
- Fix X geometry refresh for multiple bars and preserve per-bar offsets.
- Fix volume backend failures, such as a missing =amixer get Capture= control,
  so they retain the last good value instead of breaking the refresh timer.
- Fix module failures during startup so they do not leave slothbar-mode in a
  state that requires manual cleanup before retrying.
- Fix several hotplug, damage, pointer, and workspace lifecycle edge cases
  found by the live Xwayland and Wayland tests.

** Tests and tooling

- Add unit coverage for formatting, damage spans, module construction,
  lifecycle, singleton handling, font refresh, failure containment, and
  multi-bar behavior.
- Add live headless-sway Wayland and Xwayland smoke tests covering:
  - multi-bar output expansion and hotplug
  - multiple =:each= entries
  - runtime reconfiguration
  - multi-bar damage and pointer routing
  - theme and font-scale fan-out
  - output scale changes
  - two-bar geometry refresh
  - XEmbed tray singleton behavior
  - shared focus/sysinfo providers
  - operation without elwl on X
- Add a cold-font-cache benchmark task.
- Add a MELPA package build/install test that includes the Wayland backend
  and verifies it fails cleanly when elwl is unavailable.
- Add this changelog.

* 0.30.2 - 2025-12-13

** Added
- =slothbar-workspaces-truncate-to-width= customization.

** Changed
- Workspaces default to a variable-pitch font.

** Fixed
- Correct the declaration of =shorten-strings= in the workspaces module.

* 0.30.1 - 2025-07-06

** Fixed
- EWMH setup when =slothbar-ewmh-mode= is enabled before module
  initialization.

* 0.30.0 - 2025-06-26

** Added
- all-the-icons and nerd-icons dependencies.
- EWMH and urgency support in the workspaces module.
- Light-background foreground colors and theme-change responsiveness.

** Changed
- Better behavior for missing fonts and glyphs.
- Better behavior when customize variables are reset.
- Enable/disable the bar with =M-x slothbar-mode= instead of separate
  start/exit commands.

** Fixed
- StumpWM, spectrwm, and i3 integration issues.
- The tray now exits safely when another tray is already running.

* 0.28.2 - 2025-06-15

** Changed
- Rename the project to slothbar and update documentation.
- Load fonts asynchronously at startup and when font candidates change.
- Watch font-related settings only while the bar is enabled.
- Use =margin-y= when calculating struts so gaps work correctly.

** Fixed
- Battery status refresh after module initialization.
- Color-zone customization types and documentation.
- herbstluftwm workspaces listener startup and shutdown.
- Several X11 resource and refresh issues.
